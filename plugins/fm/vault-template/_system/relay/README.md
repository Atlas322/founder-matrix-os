# relay — сешн ↔ дүрийн бүртгэл

- `registry.json` — сешн ↔ дүрийн зураглалын **цорын ганц** эх үүсвэр (`/fm:setup` үүсгэнэ, `/fm:role` бичнэ). Гараар бүү засаарай.
  - `roles`: дүр бүрийн note, суваг, бүлэг, хавтас, `private`.
  - `sessions`: сешн бүрийн `role`, `device`, `title`.
- Энэ хавтас таны vault-д л байна; git-д, Discord-д бүү хуулаарай.
- `private: true` дүрийн сешн статус, Discord руу юу ч илгээхгүй.
