# fm:daily - өдрийн тэмдэглэл

Энэ skill өнөөдрийн өдрийн note-ийг үүсгэнэ эсвэл шинэчилнэ.

**Гол зарчим:** хэрэглэгчийн бичсэн юу ч **хэзээ ч дарж бичигдэхгүй**. Агент зөвхөн өөрийн хэсгүүдийг нэмж, шинэчилнэ.

- Vault: `${user_config.vault_path}` (доор `<V>`).
- Дүрэм: `<V>/_system/BOOT.md`.
- Огноо: `$ARGUMENTS`-д `YYYY-MM-DD` өгсөн бол тэр огноо. Үгүй бол `date +%F`. Гарагийг `date +%u` (1 = Даваа) командаар ав. Огноо болон гарагийг хэзээ ч бүү таа.

Гарагийн нэр: 1 Даваа · 2 Мягмар · 3 Лхагва · 4 Пүрэв · 5 Баасан · 6 Бямба · 7 Ням.

## 1. Үүсгэх эсвэл нээх

Зам: `<V>/02-GTD/daily/YYYY-MM-DD.md`

### Файл байхгүй бол

1. `<V>/_system/templates/Daily Note.md`-г Read-ээр унш.
2. Загварын тэмдэгтүүдийг гараар соль. Obsidian ажиллаагүй тул plugin орлуулахгүй.

   | Тэмдэгт | Юугаар солих |
   |---|---|
   | `{{date:YYYY-MM-DD}}`, `{{date}}`, `<% tp.date.now("YYYY-MM-DD") %>` | огноо |
   | `{{date:dddd}}`, `<% tp.date.now("dddd") %>` | монгол гарагийн нэр |
   | `{{title}}`, `<% tp.file.title %>` | `YYYY-MM-DD` |
   | `{{time}}`, `{{time:HH:mm}}` | `date +%H:%M` |
   | `<% tp.file.cursor() %>`, бусад `<% ... %>` | хоосон (тэмдэгт бүү үлдээ) |

3. Загвар байхгүй бол хамгийн бага бүтэцтэй note үүсгэ:
   - frontmatter: `date`, `type: daily`, `tags: [daily]`, `ai-first: true`, `focus: []`;
   - `# YYYY-MM-DD - <гараг>`;
   - `## For future agent`;
   - `## 🎯 Өнөөдрийн гол 3`;
   - `## 💼 Ажил`;
   - `## 🌙 Оройн дүгнэлт`.
4. `02-GTD/daily/` хавтас байхгүй бол үүсгэ.

### Файл байгаа бол

Read-ээр унш. Дараагийн бүх өөрчлөлт **Edit-ээр, хэсэг хэсгээр** хийгдэнэ. Файлыг бүхэлд нь Write-аар дарж бичихгүй.

## 2. Хэрэглэгчийн оролт - хөндөхгүй

Дараах зүйлс **хэрэглэгчийнх**. Тэдгээрийг бүү өөрчил, бүү эрэмбэл, бүү устга:

- frontmatter-ийн `focus:`, `mood:`, `energy:`, `habit_*:` талбарууд;
- `**Өдрийн зорилго:**`, `**Талархал:**`, `## 🏠 Хувийн`, `## 📥 Inbox` хэсгийн текст, мөн `🌙 Оройн дүгнэлт`-ийн хэрэглэгчийн мөрүүд (хуучин загварт `Intention`, `Grateful for`, `Personal`);
- хэрэглэгчийн сэтгэгдлийн мөрүүд (`> 💬 ...` гэх мэт).

Хэрэглэгч эдгээрт өнөөдрийн хүсэлт эсвэл асуулт бичсэн байвал түүнийг **шинэ оролт** гэж уншаад хариулт эсвэл task болгох эсэхийг асуу.

## 3. Фокус хэсгийг бүтээх

`## 🎯 Өнөөдрийн гол 3` хэсгийг (хуучин загварт `## 🎯 Today's Focus`) дараах журмаар бүтээнэ:

1. **Хэрэглэгчийн фокус эхэнд байна.** `focus:` жагсаалтад зүйл байвал тэдгээрийг дарааллаар нь харуул: 🔴 #1, 🟡 #2, 🟢 #3. Хэсгийн биед аль хэдийн фокусын мөр байвал хэвээр үлдээ.
2. **Хугацаа нь болсон task-ууд.** `<V>/02-GTD/tasks/` дотор Grep хийж `due:` талбартай файлуудыг ол. Frontmatter-ийг уншаад дараах нөхцөлийг шалга:
   - `status` нь `completed`, `cancelled` (хуучин `done`)-ийн аль нь ч биш;
   - `due` нь өнөөдөр эсвэл түүнээс өмнө;
   - `owner` нь `me`, `"@${user_config.member}"` эсвэл энэ сешний дүр.

   Нөхцөл хангасан task-уудыг фокусын **доор** `### 📌 Хугацаа болсон` гэсэн дэд хэсэгт жагсаа. Мөрийн хэлбэр: `- [[02-GTD/tasks/<нэр>]] - due YYYY-MM-DD` (хугацаа хэтэрсэн бол ⚠️ тэмдэг нэм).

   Task хэзээ ч хэрэглэгчийн фокусыг шахаж, орлохгүй.
3. **Өчигдрөөс үлдсэн.** Өчигдрийн daily note-ийн `**Маргаашийн #1:**` (хуучин загварт `**Tomorrow's #1 priority:**`) мөрийг уншина. Мөн `_system/STATUS.md` дахь энэ дүрийн мөрийн «дараагийн алхам» хэсгийг уншина. Эдгээр нь хоосон биш бол `### ↪️ Өчигдрөөс` дэд хэсэгт нэг мөрөөр бич.

Агентын дэд хэсгүүдийг (`📌`, `↪️`) дахин ажиллуулахад **бүхэлд нь сольж** шинэчил. Ингэснээр давхардал үүсэхгүй.

## 4. Ажлын холбоос (Work Log)

Энэ ярианд эсвэл өнөөдрийн логт (`_system/logs/<огноо>.md`) гарсан атом, task, reference-ийн холбоосыг `## 💼 Ажил` хэсэгт (хуучин загварт `## 💼 Work Log`) нэм. Мөр бүр **зөвхөн холбоос** байна: `- [[...]] - нэг мөр`. Аль хэдийн байгаа холбоосыг дахин бүү нэм.

Хуанли (Google Calendar) холболт v0-д **байхгүй** (v0.2). Хуанлийн хэсгийг бүү зохио.

## 5. Хувийн санхүүгийн сануулга (зөвхөн Санхүү дүрийн сешнд)

Энэ алхмыг **зөвхөн** context-д `PRIVATE сешн` гэж байгаа Санхүү дүрийн (`role: finance`) сешн хийнэ. Бусад дүр `04-Areas/Business/finances/private/` хавтсыг уншихгүй тул энэ алхмыг чимээгүй алгасна.

Санхүү дүрийн сешн дараах шалгалтыг хийнэ:
1. `private/` доторх `type: bill`, `status: active` note-уудаас дараах нөхцөлийг хангасныг ол:
   - `due_day` нь өнөөдрийн өдөр эсвэл түүнээс өмнө;
   - `last_paid` нь энэ сард биш.
2. Ийм bill байвал фокусын доор нэг мөр нэм:

```
- 🔒 Төлбөр: N зүйл хугацаа болсон → [[04-Areas/Business/finances/private/Сарын төлбөр]]
```

- **Дүн, байгууллагын нэр, данс бүү бич.** Тоо болон холбоос л байна.
- Bill олдохгүй бол юу ч бүү нэм.

## 6. Лог ба буцаах

1. Шинээр үүсгэсэн бол `_system/logs/<огноо>.md`-д нэг мөр нэм. Цагийг `date +%H:%M`-ээр ав.
   ```
   - **HH:MM** · <дүр> → daily: [[02-GTD/daily/YYYY-MM-DD]]
   ```
   Шинэчлэлт бүрд лог мөр бүү нэм. Зөвхөн үүсгэсэн үед нэмнэ.
2. Хэрэглэгчид note-ийн замыг өг. Хамт 3 мөр товчлол харуул:
   - фокус N;
   - хугацаа болсон task N (⚠️ хэтэрсэн M);
   - өчигдрөөс үлдсэн 1 мөр.

## Хориг

- Хэрэглэгчийн оролтыг дарж бичихгүй, эрэмбэлэхгүй.
- Task, үйл явдал, хуанлийн бичлэг зохиохгүй. Бодит файлаас л авна.
- Дуусаагүй Templater тэмдэгт (`<% %>`, `{{ }}`) үлдээхгүй.
- `.obsidian/`-д хүрэхгүй. Vault-аас гадуур бичихгүй.
