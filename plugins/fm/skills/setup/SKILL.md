# /fm:setup — vault үүсгэх ба эхний алхам

Гишүүн бүр **өөрийн хувийн** vault-тай. Тэр нь багийн төслүүдийг ч хөтөлнө. Энэ skill vault-ийн араг ясыг `vault-template`-ээс үүсгээд, гишүүнтэй хамт гурван зүйлийг бөглөнө: **SOUL.md → эхний төслүүд → дүрийн бүртгэл**.

Vault-ийн зам: `${user_config.vault_path}`
(Хоосон эсвэл `${...}` хэвээр харагдвал гишүүнээс бүтэн замыг асуу. Plugin-ийн тохиргоог `/config`-оос засаж болно.)

## Хатуу дүрэм

- Vault-аас **гадуур юу ч бичихгүй**. `~/.claude`, `.obsidian/`, бусад хавтсыг хөндөхгүй.
- Байгаа файлыг **дарж бичихгүй**. Vault хоосон биш бол эхлээд юу байгааг харуулж, зөвшөөрөл ав.
- Хувийн өгөгдлийг (гэр бүл, санхүү, нууц үг, token) асуухгүй. Гишүүн өөрөө бичвэл зөвхөн vault-д үлдэнэ.
- Санхүү нь хувийн модуль: `04-Areas/Business/finances/private/` үүснэ, гэхдээ агуулгыг нь `/fm:finance` л хөтөлнө.

## Алхам 1 — Скрипт ажиллуул

Гишүүний нэрийг асуу (Home.md-д гарна, хүсэхгүй бол `TBD`). Эхлээд **dry run** — юу ч бичихгүй, тайлан л гаргана:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/fm_setup.py" "${user_config.vault_path}" --member "<нэр>" --dry-run
```

Тайланг харуулж зөвшөөрөл аваад жинхэнээр нь:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/fm_setup.py" "${user_config.vault_path}" --member "<нэр>"
```

Скрипт байгаа файлыг **хэзээ ч дарж бичихгүй** («skipped» гэж мэдээлнэ), `.obsidian/`-ийг хуулахгүй, `_system/relay/registry.json`-г дүрийн жагсаалттай үүсгэнэ. Хуучин vault-д шинэ дүр нэмэх бол `--merge-registry`.

Windows дээр `python3` байхгүй бол `python` эсвэл `py -3`. Зам хоосон зайтай тул **заавал хашилтад** бич.

Гаралтыг гишүүнд товч хэл: хэдэн хавтас, файл үүссэн, юуг алгассан (аль хэдийн байсан).

## Алхам 2 — SOUL.md (5–10 минут, нэг асуулт нэг удаа)

`01-Soul/SOUL.md`-г (эсвэл template-ийн байршлыг) нээж, гишүүнээс **нэг нэгээр** асуу:

1. Чи хэн бэ — нэг өгүүлбэр (ажил, юу бүтээдэг).
2. Юуг эрхэмлэдэг вэ — 3 үнэт зүйл.
3. Энэ жил юуг заавал бүтээх вэ.
4. Юу хийхгүй вэ (anti-goal).
5. Хэрхэн ярилцахыг хүсэх вэ (товч/дэлгэрэнгүй, хэл).

Хариуг гишүүний үгээр бич, өөрөө зохиохгүй. Мэдэгдэхгүй зүйлийг `TBD` гэж үлдээ.

## Алхам 3 — Эхний төслүүд (1–3)

«Одоо идэвхтэй хийж байгаа 1–3 ажлаа нэрлэ» гэж асуу. Төсөл бүрийг `/fm:project`-ийн дүрмээр үүсгэ:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/project/scripts/fm_project.py" new "${user_config.vault_path}" "<Нэр>" --state active --context work --goal "<нэг мөр>"
```

Нэрийг кириллээр **баталгаажуул** (латин галиг хоёр утгатай байж болно). Багийн төсөл бол `area: Business`, хувийнх бол `context: home`.

## Алхам 4 — Дүрийн бүртгэл

Дүрийн тэмдэглэлүүд `04-Areas/AI Team/ai-workers/`-д байна. Жагсаалтыг харуул:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/role/scripts/fm_role.py" list "${user_config.vault_path}"
```

Тайлбарла: **бүгд Agent, зөвхөн дүрээрээ ялгарна.** Сешн бүрийг нэг дүрд холбоно (`/fm:role <slug>`). Эхлэхэд GTD сешн хангалттай. Том төсөлд тусдаа ажлын дүр хэрэгтэй бол `1x <Төсөл>.md` нэртэй, `type: agent-role` + `role: <slug>` frontmatter-тэй тэмдэглэлийг `01 Project.md`-ийн бүтцээр үүсгэхийг санал болго (гишүүн батална; дүүргээд `fm_setup.py … --merge-registry`).

Энэ сешнийг шууд холбох уу гэж асуу → тийм бол `/fm:role gtd`.

## Алхам 5 — Дүгнэлт

Гишүүнд хэл:
- Obsidian-оор vault-аа нээх (`.obsidian/` тохиргоог гишүүн өөрөө удирдана).
- Өдөр тутмын эхлэл: GTD сешн → `/fm:task`, `/fm:project`.
- Санхүү: «санхүү» сешнийг `/fm:role finance`-ээр холбож `/fm:finance`.
- Discord, Figma, Notion зэрэг хэрэгсэл v0.2-д нэмэгдэнэ.

Юу үүссэн, юу `TBD` үлдсэнийг жагсааж дуусга.
