# fm:track - ярианы дундах checkpoint

**Зорилго.** Одоог хүртэлх ярианаас хадгалах ёстойг хурдан барьж аваад, **ажлаа таслалгүй үргэлжлүүлэх**. Энэ нь сешний төгсгөл биш, дундын checkpoint юм.

- Vault: `${user_config.vault_path}` (доор `<V>` гэж товчилно).
- Дүрэм: `<V>/_system/BOOT.md` (context-д байхгүй бол Read-ээр унш).

| | fm:track | fm:save | fm:update |
|---|---|---|---|
| Хэзээ | ярианы дунд, олон удаа | сэдэв/сешн дуусахад | ажлын төлөв өөрчлөгдөхөд |
| Юу | атом + task + лог мөр | бүгд (хүн, төсөл, өдрийн note) | STATUS блок + task жагсаалт |
| Дараа нь | **яриагаа үргэлжлүүлнэ** | тайлагнана | тайлагнана |

## Алхмууд

### 1. Хүрээ тогтоох

- Цагийг `date +%F`, `date +%H:%M` командаар ав. Хэзээ ч бүү таа.
- Дүрээ context-ийн `Дүр: <slug>` мөрөөс ол. Байхгүй бол `${user_config.member}`-ийг ашигла.
- `<V>/_system/logs/<огноо>.md`-ээс энэ дүрийн сүүлийн мөрийг ол.
- Энэ сешнд өмнө нь `/fm:track` эсвэл `/fm:save` ажилласан бол **түүнээс хойшхийг л** ав. Үгүй бол сешний эхнээс ав.

### 2. Ялгах

Дараах дөрвөн зүйлийг л хайна:

- **Шийдвэр.** Хэрэглэгчийн сонголт, батлагдсан арга, чиглэлийн өөрчлөлт.
- **Ойлголт эсвэл баримт.** Дахин хэрэглэгдэх нэг санаа: зарчим, сургамж, хэмжилтийн үр дүн.
- **Мэдэхгүй зүйл.** Нээлттэй асуулт (`kind: question`). Хэрэглэгчийн одоогийн бодлыг буруу ч гэсэн хадгална. Хожим хариулт гарахад шинэ атом бичиж `answeredby:` заагч нэмнэ.
- **Task.** Үүссэн, өөрчлөгдсөн эсвэл дууссан task.

Жижиг зүйлийг атом болгохгүй. «Ирээдүйн агент үүнийг хайх уу?» гэсэн асуултад «үгүй» бол алгас.

### 3. Давхардал шалгах

- Атом бүрийн түлхүүр үгийг `<V>/06-Atomic/` дотор Grep-ээр хай.
- Ижил санаа байвал шинээр бүү бич.
  - Шинэ нотолгоо гарсан бол тэр атомд `**Холбоос:**` эсвэл эх сурвалж нэм.
  - Санаа өөрчлөгдсөн бол шинэ атом бичээд `supersedes:`-ээр холбо. Хуучин атомын агуулгыг засахгүй.

### 4. Бичих

**Шийдвэр**
- Зам: `06-Atomic/decisions/YYYY-MM-DD - <ascii-slug>.md`
- Загвар: `_system/templates/Session Decision.md`. `{{date:...}}`, `{{title}}`, `<% ... %>` тэмдэгтийг бодит утгаар соль. `role:` талбарт дүрийн slug-аа бич.

**Ойлголт / асуулт**
- Зам: `06-Atomic/knowledge/YYYY-MM-DD - <ascii-slug>.md`
- Загвар: `_system/templates/Atomic.md`
- Загвар байхгүй бол frontmatter-т дараах талбаруудыг тавь:
  - `date`
  - `type: atomic`
  - `kind: insight|fact|question`
  - `tags`
  - `confidence: stated|high|medium|speculation`
  - `sources`
  - `role: <дүрийн slug>`
  - `projects: [...]` эсвэл `areas: [...]` (PARA гэр)
  - `ai-first: true`

**Атомын бие**
- `# Монгол гарчиг`
- `## For future agent` (2-3 өгүүлбэр)
- санаа
- `**Холбоос:**` мөр

**PARA гэр**
- Атом бүр `03-Projects/`, `04-Areas/` эсвэл `05-Resources/` доорх дор хаяж нэг note руу холбогдоно.
- Гэрийн note-д (жишээ нь төслийн `## Гол шийдвэр` хэсэгт) атом руу заасан нэг мөр нэм. Read → Edit ашигла.

**Task**
- Зам: `02-GTD/tasks/<Гарчиг>.md`
- Загвар: `_system/templates/Task.md`.
- Шаардлагатай талбарууд: `type: task`, `status` (`inbox` · `next-action` · `waiting` · `someday` · `completed` · `cancelled`), `owner` (`me` · `"@Нэр"` · дүрийн slug), `priority` (`high` · `medium` · `low`), `context` (`work` · `home`), `project`, `ai-first: true`.
- Байгаа task-ийг бол зөвхөн `status`/`updated`-ийг шинэчил.

### 5. Лог мөр

`<V>/_system/logs/<огноо>.md` файлын төгсгөлд нэг мөр нэм:

```
- **HH:MM** · <дүр> → track: [[атом1]] · [[атом2]] · [[task]]
```

- Read → Edit-ээр нэмнэ. Файл байхгүй бол үүсгэнэ.
- Мөрөнд зөвхөн холбоос байна, агуулгыг бүү бич.
- Өмнөх мөрүүдийг бүү засварла.

### 6. Товч мэдэгдэх ба ҮРГЭЛЖЛҮҮЛЭХ

Хэрэглэгчид нэг-хоёр мөрөөр мэдэгдэ:

```
📌 track: атом 2, task 1 → [[...]], [[...]]
```

Дараа нь **яриагаа шууд үргэлжлүүл**:
- Сешнийг бүү дуусга, бүү дүгнэ.
- «Өөр юу хийх вэ?» гэж бүү асуу.
- Track дуудагдахаас өмнө хийж байсан ажил руугаа буц.

## 🔒 Хувийн санхүү

Хувийн санхүүгийн хавтас (`04-Areas/Business/finances/private/`) болон `private: true` бүхий note-ийг зөвхөн **Санхүү дүр** (`role: finance`) бичнэ.

- **Санхүү дүргүй сешн:** санхүүгийн зүйлийг бүү барь, бүү бич. Мэдэгдэлдээ зөвхөн «🔒 N зүйл - Санхүү дүрийн сешнд хадгал» гэж хэл.
- **Санхүү дүрийн сешн** (context-д `PRIVATE сешн` гэж байгаа):
  - атом **бүү** бич;
  - зөвхөн тэр хавтас доторх note-ийг шинэчил (`Bill` эсвэл `Finance Record` загвар);
  - лог мөрөнд зөвхөн `- **HH:MM** · 🔒 → track` гэж бич.
